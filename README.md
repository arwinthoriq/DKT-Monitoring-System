# DKT-Monitoring-System
Platform pemantauan infrastruktur IT rumah sakit berbasis web yang dibangun menggunakan Python. Aplikasi lokal ini dirancang untuk memantau status real-time PC client, manajemen jaringan lokal, serta memantau integrasi layanan kesehatan seperti BPJS, SATUSEHAT, dan TTE. Solusi terpusat untuk efisiensi dan keandalan operasional IT rumah sakit
